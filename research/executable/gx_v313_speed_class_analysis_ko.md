# Nova1492 GX 분석 v3.13 — missilemove 두 번째 토큰과 방향 회전

## 로더 값

`missilemove`의 두 번째 토큰은 레코드 `+0x35`에 저장된다. 로더가 명시적으로 기록할 수 있는 값은 `1,2,3,4,5,7`이며 일치하지 않으면 초기값 `0`이 유지된다.

설치본의 공격 정의 108개는 모두 두 번째 토큰으로 `보통`을 사용하며 이는 클래스 `1`로 로드된다. 다른 클래스 이름은 현재 설치 콘텐츠에서 사용되지 않는 엔진 호환 어휘다.

## 위치 진행률과 분리

`+0x35`를 읽는 런타임 명령은 `0x00440CBB`와 `0x004416D8` 두 곳이다. 이동 타입 점프 전에 진행률 자체를 클래스별로 변환하는 분기는 없다. 따라서 이 필드를 일반적인 속도/easing 곡선 ID로 해석하면 안 된다.

- `0x00440CBB`: 클래스 7인지 검사해 방향 계산의 기준 벡터 선택을 바꿈
- `0x004416D8`: 클래스 1인지 검사해 추가 회전 행렬 경로를 실행

위치의 시간 진행은 공격 객체의 수명/거리에서 만들어진 공통 진행률과 movement type 공식이 담당한다.

## 클래스 1 회전식

클래스 1에서는 레코드 세 번째 매개변수 `param2(+0x44)`가 회전 횟수/위상 계수로 재사용된다. `t`를 공통 진행률이라 하면 회전각은 다음과 같다.

```text
objectState(+0x40) != 0: angle = 2π * param2 * t
objectState(+0x40) == 0: angle = 2π * param2 * t²
```

근거는 `0x004416E5~0x0044179E`의 `t` 또는 `t²`, `record+0x44`, π와 2.0의 연속 곱셈이다. 이 각도는 `0x00443D90`의 회전 행렬 생성기에 전달된 뒤 미사일 모델 방향 행렬에 합성된다.

설치본 베지어 정의는 `param2=0`이므로 클래스 1이어도 추가 회전량은 0이다.

## 클래스 7

클래스 7은 `0x00440D25~0x00440D8B`에서 미사일 GX 노드/행렬의 기준 방향 벡터를 조회해 기본 진행 방향에 더한다. 위치 궤적을 바꾸는 것이 아니라 모델이 바라보는 기준축을 리소스 내부 노드 방향으로 보정하는 클래스다.

## 구현 지침

- 필드 이름은 `speedClass`보다 `orientationClass`가 실제 소비 의미에 가깝다.
- 파일 호환 구조에는 원본 이름/바이트를 보존한다.
- 클래스 1과 7만 현재 확인된 특수 동작을 구현하고, 0/2/3/4/5는 기본 방향 경로로 처리한다.
- movement type의 위치식과 orientation class의 회전식을 별도 단계로 계산한다.
