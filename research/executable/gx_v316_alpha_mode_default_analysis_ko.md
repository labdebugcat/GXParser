# Nova1492 GX 분석 v3.16 — 실제 기본 알파 테스트와 Z-write 정책

## 플래그 주소와 초기화

렌더러 전역 객체는 `0x00764330`이며 알파 경로 플래그 `+0x2010D`의 절대주소는 `0x0078443D`다.

생성자 `0x00428FB5`는 다음 명령을 실행한다.

```text
mov word ptr [0x0078443D], BX
```

이 시점의 `BX`는 0이다. PE의 정적 초기 바이트도 0이며 실행 파일 전체 직접 참조 검사에서 이 주소에 대한 다른 쓰기는 발견되지 않았다. 따라서 현재 설치 실행 파일의 기본 경로는 플래그 0으로 확정된다.

## 플래그별 상태

| 플래그 | ALPHAREF/FUNC | queue 2 Z-write |
|---:|---|---|
| 0, 설치본 기본 | `0 / NOTEQUAL` | OFF |
| 1, 대체 경로 | `10 / GREATER` | ON |

`FUN_0042EAC0`이 알파 테스트 상태를 선택하고, `FUN_0042C0A0`은 플래그가 0일 때만 queue 2 진입 시 `FUN_0042B98B(0)`을 호출한다.

이 두 상태는 독립 옵션이 아니다. `GREATER/10`을 고르면서 queue 2 Z-write를 계속 끄는 조합은 원본 코드에 없다.

## 기존 구현 오류

도구는 시각적으로 가장자리를 줄인다는 이유로 `GREATER/10`을 기본 선택했지만 queue 2 Z-write는 항상 껐다. 이는 원본의 두 경로를 섞은 제3의 상태였다.

## 수정

- Native 기본값을 `NOTEQUAL/0`으로 변경
- UI에서 설치본 기본 경로를 첫 항목으로 배치
- `NOTEQUAL/0`일 때만 queue 2 Z-write 비활성화
- `GREATER/10` 대체 경로에서는 queue 2 Z-write 유지
- Blender 메타데이터 기본값을 `gx_alpha_test_ref=0`, `gx_alpha_test_func=NOTEQUAL`로 교정

이 수정은 반투명 효과가 서로 겹칠 때의 깊이 결과와 알파 가장자리 픽셀 통과 여부를 동시에 원본 기본 상태에 맞춘다.
