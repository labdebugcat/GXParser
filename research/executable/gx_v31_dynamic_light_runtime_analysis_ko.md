# Nova1492 GX 분석 v3.1 — G3DEILight 동적광원 런타임

## 결론

GX 동적광원 클래스는 `G3DEILight`, 객체 크기는 0x40바이트다. 생성자는 `FUN_00437A30`, 매 프레임 갱신은 `FUN_00437BA0`, 소멸자는 `FUN_00437B30`이다.

`gxdesc.ini`의 `lighttype`을 가진 고유 섹션 112개를 모두 내부 타입 번호로 변환했으며 미해석 값은 없다.

## 지역화 이름과 내부 타입

한국어 이름은 `datan/kr/nvtext.dat`의 연속 ID 2170~2176이며, 로더 `FUN_00464630`의 비교 순서 및 대입값과 대조했다.

| nvtext ID | 이름 | 내부 타입 | 설치본 섹션 | 런타임 크기 곡선 |
|---:|---|---:|---:|---|
| 2170 | 진동 | 5 | 16 | 사인 진동 후 마지막 약 200ms 동안 선형 감소 |
| 2171 | 포물선 | 0 | 53 | 중앙이 최대인 포물선 |
| 2172 | 선형증가 | 1 | 17 | `base × progress` |
| 2173 | 선형감소 | 2 | 15 | `base × (1-progress)` |
| 2174 | 이차증가 | 3 | 0 | `base × progress²` |
| 2175 | 이차감소 | 4 | 0 | `base × (1-progress)²` |
| 2176 | 고정 | 6 | 11 | 기본 크기를 중심으로 지속적인 사인 변화 |

고정 타입의 이름은 객체/수명 동작의 분류명이며, 실제 반경은 두 보조 파라미터가 주어지면 사인 함수로 미세 변화한다.

## 0x40바이트 G3DEILight 객체

| 오프셋 | 의미 |
|---:|---|
| +0x04 | 추적 대상 GX 인스턴스, -1이면 독립 위치 |
| +0x0C~+0x14 | 광원 위치 x/y/z |
| +0x18 | 현재 크기/반경 |
| +0x1C | 현재 packed ARGB 색 |
| +0x20 | 수명 시간 단위 |
| +0x24 | 시작 시각 |
| +0x28 | 기본 크기 |
| +0x2C | 진동 진폭 파라미터 |
| +0x30 | 진동 속도 변환값 |
| +0x34 | 하위 4비트 타입, 0x20/0x80 추가 플래그 |
| +0x35 | 대상 위치 추적 여부 |
| +0x38 | 기본 packed ARGB 색 |

생성자는 gxdesc `lighttime`에 시간 변환 상수를 곱해 +0x20에 저장하고, `lightcolor`를 packed ARGB로 바꿔 +0x1C/+0x38에 저장한다. `lightsize`는 +0x18/+0x28에 복사된다.

## 프레임 갱신

`FUN_00437BA0`은 전역 고해상도 시간을 밀리초 계열로 변환한 뒤 시작 시각과의 차이로 진행률을 계산한다.

- 수명이 0이 아니며 시간이 끝나면 연결된 GX 인스턴스의 광원 플래그를 해제한다.
- 대상 추적이 켜져 있으면 GX 인스턴스 위치를 매 프레임 +0x0C~+0x14에 복사한다.
- 0x80 플래그가 있으면 y를 큰 음수 값으로 보내 기둥형 투영 경로를 사용한다.
- 계산된 반경이 0보다 크면 `FUN_00448F10` 또는 `FUN_004570F0`으로 장면 광원 목록에 제출한다.
- 진동 타입 5는 종료 약 200ms 전에 타입 2로 바꿔 선형 소멸한다.
- `lightdiffusechange`는 타입 바이트의 0x20 플래그로 보존된다. v3.2에서 최종 합성까지 추적한 결과 현재 EXE는 이 비트를 렌더 분기에 소비하지 않으므로 legacy/호환성 필드로 정정했다.

## v3.1 도구 반영

- 모든 7개 이름을 정확한 클라이언트 타입 번호로 변환한다.
- `lighttype` 뒤의 선택적 실수 두 개를 보존한다.
- Native 보고서에 이름과 타입 번호를 표시한다.
- Blender 사용자 속성에 `gxdesc_lighttype_id`, `gxdesc_lighttype_name`, `gxdesc_lighttype_params`를 추가한다.

## 검증

- Python 문법 검사 통과
- 설치본 고유 lighttype 섹션 112개 전부 변환 성공
- 알 수 없는 타입 0개
- 두 파라미터 사용 101개, 기본 파라미터 사용 11개

이 결과는 GX 동적광원의 타입·수명·위치 추적·반경 변화 경로를 복원한 것이다. D3D 장면 광원 목록 내부의 공간 감쇠 및 최종 픽셀 합성은 후속 분석 대상이다.
